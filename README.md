## Overview

**VERDURE** is an award-winning, luxury restaurant website crafted with a museum-grade editorial aesthetic inspired by 2026 Awwwards Site of the Day design systems.

### Key Systems & Architectural Features
- **Continuous 1px Architectural Grid**: Unbroken Swiss hairline grid with exposed `+` intersection crosshairs across all viewports.
- **Dynamic Ambience Engine**: Smooth global transition between **Daylight Botanical Service** (`#F4F3EE`) and **Candlelit Evening Tasting** (`#070F0A`) with real-time token synchronization.
- **3D Hero Centerpiece & Multi-Plane Stage**: Tilt-reactive ceramic bowl showcase with live wireframe orbits, depth-stacked telemetry cards, and interactive ingredient hotspots.
- **Culinary Pillars (Feature Strip)**: Interactive expanding architectural strip (`flex-[1.4]` vs `flex-[0.8]`) with radial lighting vignettes and animated progress indicators.
- **Selected Plates (Dual-Mode Showcase)**: Seamless toggle between **`⊞ 3D Grid`** and an **`☰ Editorial Index`** featuring 16px hover shifts and cursor-following 3D preview cards.
- **Spatial Architecture Split**: Live 3-cell spatial specification grid (`CAPACITY`, `ACOUSTICS`, `LIGHTING`) with interactive 3-angle room switcher pills (`Main Dining`, `Hearth Counter`, `Botanical Courtyard`).
- **Unified Concierge & Table Picker**: 2-column architectural console featuring an interactive SVG table floorplan (`T-01` to `T-08`) with instant live assignment updates.
- **VIP Digital Table Pass**: Confirmation modal generating a luxury digital table pass with custom SVG QR code, booking reference, and direct WhatsApp share integration (`wa.me`).
- **Monumental Grid Footer**: 4-column layout with live Indian Standard Time (IST) restaurant clock, quick ambience switcher, kinetic `Back to Top` button, and edge-to-edge `16vw` watermark.

## Getting Started

### Prerequisites
- Node.js 18+ or 20+
- npm / yarn / pnpm

### Installation
```bash
# Clone the repository
git clone https://github.com/elevoradigital/verdure-restaurant.git

# Navigate into the project directory
cd verdure-restaurant

# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

### Production Build
```bash
npm run build
npm run start
```

## Deployment

Deployable seamlessly on [Vercel](https://vercel.com):
1. Import the repository `elevoradigital/verdure-restaurant` into Vercel.
2. The framework preset will automatically detect Next.js.
3. Deploy without requiring custom environment variables.
